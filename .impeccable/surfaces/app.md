# Surface brief — app (public catalog + viewer + admin chrome)

**Mode:** Operate  
**Scope:** Full replacement visual world (notation remains ink on white paper).

## Audience & job

Musicians, students, teachers scanning a licensed score library; admins ingest metadata. Fast credit-grouped scan, open work, read/practice.

## Constraints

MusicXML canonical; no Verovio on catalog index; WCAG AA; 40/44px targets; dark reading-room chrome with white notation surfaces unchanged.

## Direction

Archive finding-aid register (special collections): unified warm parchment shell, manila work surfaces, stamp-red locator for live selection. Standard web shell and controls; world via type, palette, density, extent summaries.

**Seed key:** e1c00e05 · **Form:** candidate 4 — archive finding-aid index

## Direction contract

**THESIS:** ClearClef is a controlled archive index for engraved scores—extent lines and shelf marks before atmosphere—refusing the cream-serif “gentle library” default and card-grid streaming layouts.

**OWN-WORLD:** Warm parchment canvas, manila cards, forest ink, stamp red (`#9f1239`) only for active filter/locator states. Public Sans UI, Spectral for work titles, mono for shelf marks. Squared controls (8px radius), hairline rules, dense but legible rows. Notation frames stay pure white.

**STORY:** Visitor sees how many works sit under each credit (extent), filters with a visible “active hold” state, opens a score onto a white page on a muted stand; dark mode is after-hours reading room, paper unchanged.

**FIRST VIEWPORT:** Top bar with wordmark + Catalog + theme; below, catalog H1 and filter row on manila strip; first credit block shows name + extent (“14 works”); rows with title, mono shelf line, optional preview in white mat; active filter shows red locator on the filter control.

**FORM:** Assigned index 4 — archive finding-aid; signature move = credit-group extent line + stamp-red locator on active catalog filters (raised from metro tile state ownership and lexicon guide-word discipline as section extent, not costume UI).
